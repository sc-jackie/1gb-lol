# CARD — 1gb.lol

Unofficial fan site for **CARD**, the 1GB SD card that shipped 27 January 2004 at a suggested retail of **$499.99**.

First-person voice. The joke is the price. Domain: [1gb.lol](https://1gb.lol) (bought separately).

This is not SanDisk. There is no partnership. The mascot is a cream SD card with a gold contact row and a fat **1GB** — not a SanDisk wordmark.

## Run locally

```bash
npm install
npm run dev
```

Dev server defaults to port **43127**. Open the URL printed in the terminal.

## Design lock

Cream `#EDE4D0`, gold `#C6A24A`, ink `#1A1612` chrome. Verdana body. Centered ~760px table. Tiled cream. Visitor counter.

Logo is the original 1.0GB SanDisk SD **photo** (`public/brand/card-logo-1gb.jpg`). At 48px the crop is the **1.0GB** type (`public/brand/favicon-1gb.jpg`). Hero is the 1500×500 black/red vortex banner (`public/brand/card-banner-icon-3x1.png`). Marquee: *I cost $499.99. I am 1GB. I am still here.*
